# General Hardware Store

A static storefront for General Hardware (K) Ltd, Nairobi. The site lists building materials, supports product search and category filtering, shows variant pricing, and prepares WhatsApp enquiries and orders.

## Run locally

Open `index.html` or `indexshe.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Publish with GitHub Pages

After pushing this repository, open **Settings > Pages**, choose **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder. GitHub Pages will serve the site from `index.html`.
